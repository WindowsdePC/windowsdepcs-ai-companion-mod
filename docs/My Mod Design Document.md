0.8.0 多加载器移植状态：

- 26.2 Fabric 版保留 0.7.9 的完整功能与存档兼容性。
- 1.20.1 Fabric 版使用独立兼容分支，针对旧版网络、注册表、界面和服务端 API 进行适配。
- 1.20.1 Forge 版使用独立兼容分支，针对 Forge 事件总线、网络通道和 FakePlayer API 进行适配。
- 三个版本共享模组 ID、配置语义、AI 安全动作白名单和用户数据格式；加载器专属实现不互相作为前置。
- 正式发行版同时提供三个带 Minecraft 版本与加载器标识的可安装 JAR，避免玩家下载错误文件。


0.8.3 旧版兼容修复状态：

- 1.20.1 Fabric 与 Forge 分支只保留各自参与构建的旧版 Mojang 映射源码，不再携带 26.2 的新版包名与渲染源码。
- 删除 1.20.1 不存在的金矛突进实现与 lunge 数据资源。
- 使用 1.20.1 `ResourceLocation`、`Screen`、`GuiGraphics`、`getWindow().getWindow()` 等 API 恢复 V+B、F8、C、G。
- 组合键采用直接轮询，不注册到原版“控制”列表；F8 会执行服务器权威位置查询，C 按住缩放、松开恢复。
- 补齐批量创建、PvP 教练、身份、提示词、功能状态等核心命令，并允许普通玩家读取 `config status`。


0.9.1 AI 可见性修复状态：

- 26.2 Fabric、1.20.1 Fabric 与 1.20.1 Forge 均通过原版玩家列表生命周期注册 AI，而不是只加入世界实体集合。
- 创建成功前同时验证 AI 已进入服务器玩家列表与当前维度；失败会回滚并向命令玩家报告原因。
- 单个 AI 在执行玩家脚边生成；批量 AI 在玩家身边分散生成，避免模型完全重叠。


0.9.2 完整备用 UI 状态：

- Cloth Config 环境会直接打开完整九分类管理中心，不再先进入只有设置摘要的中间页。
- 休闲系统、兼容设置与小游戏中心补充相册、旅行日志、日报、直播、音乐、宠物、社会、天气与状态查询入口。
- Minecraft 1.20.1 Fabric/Forge 使用旧版 `Screen`、`GuiGraphics` 与 `EditBox` 构建独立九分类界面，不引入 26.2 客户端类名。


0.9.3 望远镜发光状态：

- 已删除 F3+B 发光轮廓替换、客户端发光判定 Mixin 与旧设置，F3+B 恢复原版行为。
- 连续使用原版望远镜达到阈值后，服务器给范围内生物施加原版光灵箭 `GLOWING` 效果。
- 默认开启、观察 1 秒、半径 10 区块、持续 120 秒；每次举镜只触发一次。
- 每位玩家可在 UI 独立修改开关、半径、观察时间和持续时间，设置按 UUID 持久化。


0.9.4 望远镜目标条件状态：

- 新增全部生物、仅非玩家生物、仅敌对生物三种目标条件；默认保持全部生物。
- 服务器按同维度、存活状态、球形半径和目标条件过滤，并反馈实际命中数量。
- 旧设置缺少目标条件时自动迁移为全部生物；三个发行目标保持相同语义。


0.9.5 望远镜触发冷却状态：

- 新增每位玩家独立的发光触发冷却，默认 10 秒，可在 UI 或命令中调整为 1～600 秒。
- 冷却只限制新的发光脉冲，不缩短已经施加的原版发光效果；冷却期间会向观察者显示剩余秒数。
- 0.9.4 及更早的设置文件缺少冷却字段时自动迁移为 10 秒默认值。


0.9.6 望远镜目标上限状态：

- 新增每次发光脉冲的命中数量上限，默认 256，可在 UI 或命令中调整为 1～1024。
- 符合条件的目标超过上限时按与观察者的距离排序，只对最近目标施加原版发光效果，并反馈符合条件总数与实际命中数。
- 0.9.5 及更早设置文件缺少上限字段时自动迁移为 256；三端保持相同范围与排序语义。


0.9.7 本地 UI 与功能入口状态：

- V+B 直接进入完整九分类中心，EclipseUI 数值页改为中心内的可选现代化入口。
- 新增独立小游戏中心弹窗，五个小游戏的逻辑与成绩记录可在客户端纯本地运行。
- AI 宠物与 AI 竞技场加入明确的独立弹窗入口，不再要求玩家记忆命令。
- 26.2 Fabric 的核心 UI 操作经带边界校验的自定义网络载荷直接调用服务端管理器；命令仅作为控制台和兼容回退保留。


0.6.9 实现状态：

- 已完成默认关闭的结构、群系与维度指南针；目录读取服务器动态注册表并支持模组内容
- 已完成搜索、分类、AR 方向、目标维度、剩余方块和行程进度 HUD
- 已完成管理员传送模式与历史边境之地坐标导航

实现状态（0.7.0）：

- 已完成稳定独立 UUID、玩家名称、维度位置、模式、目标、提示词和皮肤数据持久化
- 服务器启动后会恢复 AI FakePlayer 身份，关闭或移除前主动保存独立 PlayerAdvancements
- AI 可获得原版与模组数据包进度，并可通过 identity/advancements 命令查询
- 身份文件对名称、UUID、坐标和文本长度进行校验，单条损坏不会伪造成有效身份


自动行为实现状态（0.7.1）：

- 每个 AI 可独立开启自动连续决策，默认关闭，调用间隔可设为 5 秒至 1 小时
- 自动任务会依据空闲、猎人、队友或 PvP 教练模式选择对应提示词、目标和天眼快照
- 自动设置随 AI 身份持久化，并在服务器重启后恢复
- API 未配置、AI 正在思考或参加竞技场时不会发起重叠请求
- 自动结果仍只允许聊天、短距离移动与等待，不允许任意命令、传送或作弊能力


多 AI 协作实现状态（0.7.2）：

- 已完成持久化协作组，每组支持 2～16 名已登记 AI、共享任务和一名领队
- 成员可提出计划并分别投赞成或反对票；只有取得严格多数票才形成共识
- 成员可投票选举领队；候选取得严格多数票后自动当选
- 重复投票会更新原选择，不会增加虚假票数；已经通过或否决的提案不可再次改票
- 协作任务、领队和最近通过的共识会加入成员后续手动与自动决策的观察信息
- 协作组、提案和投票均设置数量、成员身份与文本长度边界
